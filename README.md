Project Overview

A computer hardware project where I assessed an existing PC, identified suitable upgrades and installed new hardware to improve its performance and suitability for graphic design software.

What I Did
Assessed the existing PC hardware and identified areas for improvement.
Replaced the HDD with an SSD.
Upgraded the RAM from 4GB to 8GB.
Installed a new graphics card.
Replaced the network card.
Considered hardware compatibility before installation.
Created a maintenance plan for the system.
Created and carried out a test plan for the hardware.
Testing

I tested the CPU, RAM, SSD and GPU to check their performance and compatibility with the expected workload. The SSD was tested for reading and writing files, while the CPU, RAM and GPU were tested under higher workloads.

The testing helped identify whether the installed components were working correctly and suitable for the intended use.
